# Yasal metinler (taslak)

Bu klasördeki metinler Türkiye'deki internet satışı kurallarına (6502 sayılı Tüketicinin Korunması Hakkında Kanun, Mesafeli Sözleşmeler Yönetmeliği, 6698 sayılı KVKK) göre hazırlanmış **taslaklardır**. Avukat görüşü yerine geçmez. Satışa açmadan önce bir avukata ya da en az mali müşavire gösterilmeli.

## Doldurulacak yerler (köşeli parantez)
- `[SATICI ADI / UNVANI]`: şahıs ise Arzu Arslan; şirket kurulunca şirket unvanı
- `[ADRES]`, `[TELEFON]`, `[E-POSTA]`
- `[VERGİ DAİRESİ / VERGİ NO]` ve varsa `[MERSİS NO]`
- `[KARGO FİRMASI]`, `[TESLİMAT SÜRESİ]`, `[İADE KARGO ÜCRETİNİ KİM ÖDER]`
- Şahıs olarak satış yapılacaksa: fatura/vergi durumu ve ETBİS kaydı gerekip gerekmediği (mali müşavire sorun).
